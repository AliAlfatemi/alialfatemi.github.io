Featured system · Open source

warbler_yolo

GitHub repository ↗

warbler_yolo turns unannotated field images into a reproducible fine-grained recognition workflow. It segments and crops foreground subjects, creates standardized data splits, then trains and evaluates a YOLO11 classifier through a reusable command-line pipeline.

Prepare · Segment · Crop · Split · Train · Evaluate
