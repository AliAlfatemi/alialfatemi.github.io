Case study / 01 · AI for Network Security

Noise-Tolerant DDoS Detection for Edge Networks

Edge defenders need reliable attack detection when traffic is noisy, attack patterns shift, and compute budgets rule out unnecessarily deep models.

System
A Gaussian shallow neural network injects controlled noise during training to improve robustness without adding inference-time overhead.
Methods
Gaussian noise regularization · Shallow neural networks · Flow-level classification
Evaluation
The study benchmarks the compact model on public and real-world DDoS datasets, including ablations for robustness, convergence, memory, training time, and parameter count.
Why it matters
A practical path toward low-latency monitoring for edge, IoT, and computational social systems.

Case study / 02 · LLMs + Network Defense

Two-Stage DDoS Detection with Language-Model Embeddings

Application-layer attacks can hide signals in textual protocol fields that purely numeric flow models do not capture.

System
Numeric traffic features are fused with all-MiniLM-L6-v2 text embeddings, then passed through two XGBoost stages for detection and attack-family classification.
Methods
Text embeddings · Numeric–textual fusion · Two-stage XGBoost
Evaluation
On a curated ML-EdgeIIoT subset, the paper reports 100% accuracy for Normal-versus-DDoS detection and 99.91% for second-stage subclass classification.
Why it matters
Fine-grained UDP, ICMP, TCP, and HTTP attack labels can support more targeted triage and mitigation in IoT and edge environments.

Case study / 03 · Computer Vision

Foreground-Centric Fine-Grained Recognition

Fine-grained classifiers often learn background shortcuts instead of the subtle subject features that distinguish similar categories.

System
Detected subjects are isolated, standardized, and classified as foreground-centric views so the model attends to diagnostic morphology rather than incidental context.
Methods
Instance segmentation · Foreground standardization · Fine-grained classification
Evaluation
Across visually similar bird species, the paper reports consistent gains in accuracy and per-class reliability, with the largest improvements for confusable categories.
Why it matters
The same modular strategy can transfer to ecological monitoring, inspection, agriculture, and biomedical imaging.

Case study / 04 · Language + Explainable AI

Explainable Arabic Grammatical Error Correction

Arabic error correction needs both accurate edits and feedback that identifies the error type and the evidence behind the correction.

System
MTAGEC unifies correction tokens, error labels, and evidence pointers in a single encoder–decoder sequence-generation architecture.
Methods
Multi-task generation · Pointer networks · Synthetic data
Evaluation
The open-access study builds a 21.8-million-pair synthetic corpus and reports AraT5 F0.5 scores of 80.02 and 81.73 on QALB-2014/2015, plus 69.6% explanation accuracy.
Why it matters
Joint correction and rationale generation supports more transparent language-learning and writing-assistance systems.
