Project story / 03

Foreground-Centric Fine-Grained Recognition

Fine-grained visual classifiers can learn background shortcuts instead of the subtle subject features that distinguish similar categories.

System
A first-author pipeline that centers detected foreground subjects before classification to study robustness in fine-grained bird recognition.
Methods
Instance segmentation · Foreground standardization · Fine-grained classification
Evaluation
The peer-reviewed Signal, Image and Video Processing article compares the foreground-centric approach within a controlled recognition pipeline.
Relevance
Visual inspection, biodiversity monitoring, and recognition systems operating across changing environments.

Project story / 04

Vision–Language Image Captioning with ViT and GPT-J

Image captioning requires a model to align visual representations with coherent language while retaining relevant scene context.

System
A first-author vision encoder–language decoder study integrating a Vision Transformer with GPT-J for image caption generation.
Methods
Vision Transformers · GPT-J · Encoder–decoder learning · Image captioning
Evaluation
The published AIPR chapter describes training and evaluation on image-caption data using established language-generation measures.
Relevance
Accessible visual interfaces, media understanding, and multimodal information systems.
