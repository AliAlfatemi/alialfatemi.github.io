# Self-hosted fonts

Both files are the Latin-subset variable-weight (400–700) woff2 builds served by Google Fonts, downloaded once and vendored here so the site makes no request to any font CDN at runtime.

- `ibm-plex-sans-latin-variable.woff2` — IBM Plex Sans, © IBM Corp, [SIL Open Font License 1.1](https://openfontlicense.org/).
- `jetbrains-mono-latin-variable.woff2` — JetBrains Mono, © JetBrains s.r.o and contributors, [SIL Open Font License 1.1](https://openfontlicense.org/).

Both are redistributable under the OFL. See `css/styles.css` for the `@font-face` declarations.
